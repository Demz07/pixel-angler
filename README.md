# PIXEL ANGLER - live site root

Ang folder na ito = ROOT ng GitHub repo. Live ang laro sa index.html.
- index.html / manifest.webmanifest / sw.js / icons = ang website + PWA
- dev/ = source code ng laro (template, assets, build scripts) para sa IDE mo

Pages setup: Settings -> Pages -> Deploy from a branch -> main / (root).
Pag nagbago ang laro: dev/make_pages.py ang magsesync ng bagong build dito.
